# Sample Project

This page demonstrates how a project README is displayed.

## Overview

A project document should remain comfortable to read even when it contains headings, lists, images, tables, and source code.

## Features

- One layout with automatic index detection
- Responsive typography
- Scrollable code blocks and tables
- No project-specific theme configuration

## Example

```yml
remote_theme: k4nkan/portfolio-minimum-theme
```

| Element | Purpose |
| --- | --- |
| Index | Find a project |
| Document | Understand a project |

> The README remains the source of truth.
